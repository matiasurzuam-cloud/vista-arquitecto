# Campaña audiovisual 3 Vértices

Estrategia: **1 video gratuito de presentación + 3 videos comerciales**, formato vertical 9:16
(1080 × 1920, 30 fps, H.264 + AAC, −14 LUFS) para Reels, TikTok y Shorts.

Todos los videos comparten la identidad del sitio web:

| Elemento | Valor |
| --- | --- |
| Fondo profundo | `#04131f` |
| Azul petróleo (marca) | `#173b5d` |
| Azul acento | `#0f5da8` |
| Celeste destacado | `#8fc8ff` |
| Papel / claro | `#f4f7f9` |
| Tipografía | Neutra Text (light para titulares, bold para subtítulos, *bold italic* para la palabra acento). Cifras en Inter para que «A0» se lea correctamente |
| Logo | `src/assets/logo/logo-3-vertices.png` |
| Motivo gráfico | Triángulo (los «tres vértices»): transición de iris triangular, retícula de plano, eyebrow con línea |
| Fotografías | Proyectos reales del sitio (`src/assets`) |

Recursos comunes a todas las piezas: HUD con logo arriba, textos/subtítulos dinámicos palabra por palabra
(la palabra activa se resalta en celeste), música instrumental original, efectos sonoros (whoosh en
transiciones, "tick" suave al aparecer cada frase, golpe grave en el gancho, riser + impacto en el cierre), cierre con logo animado + `www.3vertices.cl`
+ WhatsApp. Zonas seguras respetadas (sin texto importante en los 220 px superiores ni los 380 px inferiores).

## Derechos y licencias
- **Música y efectos:** composición original generada por código (`scripts/music.py`), sin muestras de terceros → apta para publicidad.
- **Locución:** la versión publicada no lleva voz. El pipeline sigue generando una pista guía (Kokoro-82M, Apache 2.0) que solo define los tiempos de los subtítulos; con `VOZ=1` se incluye en la mezcla. Para una voz humana, grabar los textos y reemplazar `vo.wav` respetando los tiempos de `timeline.json`.
- **Fuentes:** Neutra Text (del sitio, licencia del estudio) + Inter (OFL) para cifras.
- **Imágenes:** proyectos propios del estudio.

## Cómo regenerar
Los guiones están en `scripts/content.py`. Para editar un texto, cambiarlo ahí y volver a producir:

```bash
pip install kokoro-onnx soundfile scipy pillow
# modelo de voz: kokoro-v1.0.onnx y voices-v1.0.bin desde
# https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
bash campaign/scripts/make.sh /tmp/work /ruta/a/voices campaign/output
```

| Script | Función |
| --- | --- |
| `content.py` | Guiones, escenas e imágenes de las 4 piezas |
| `build_audio.py` | Locución, línea de tiempo y subtítulos `.srt` |
| `music.py` | Música original + efectos, con *ducking* bajo la voz |
| `player.html` / `player.js` | Motor de animación (cada escena y transición) |
| `render.cjs` | Render cuadro a cuadro con Chromium → H.264 |
| `mix.sh` | Mezcla final y normalización a −14 LUFS |

Los MP4 finales quedan en `campaign/output/` (ignorado por git para no inflar el repositorio): versión para redes (~6 Mbps, 27–34 MB) y `output/master/` en alta calidad (~14 Mbps).
